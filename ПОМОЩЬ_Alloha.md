# Alloha: что запустить и почему прошлая команда не сработала

## Почему `python3` не нашёлся

Python у вас **есть** — `python --version` показывает `Python 3.12.8`.
Не сработало вот что: в Windows команда установщика называется `python`,
а `python3` — это ярлык-заглушка из Microsoft Store. Она есть всегда, но
настоящий Python по ней не запускается, и выходит сообщение
«Python was not found; run without arguments to install from the Microsoft
Store». Настоящий Python при этом жив — просто зовут его иначе.

Правило простое: **в Windows — `python` (без цифры 3), в Linux — `python3`.**
Это моя ошибка в инструкции, я писал под Linux.

## Самое короткое: проверить прямо в приложении

Приложение у вас уже работает, поэтому ничего скачивать не надо. В папке
проекта (`E:\Develop\LS Project TV Overlay`):

```
python -m tvhost2.alloha_check "ССЫЛКА_НА_СТРАНИЦУ_С_ВИДЕО"
```

Вместо `ССЫЛКА_НА_СТРАНИЦУ_С_ВИДЕО` — адрес страницы целиком, в двойных
кавычках. Например:

```
python -m tvhost2.alloha_check "https://zlord.org/23127-detektiv-xole.html"
```

Окно приложения при этом можно не закрывать: команда только читает, ничего
не меняет.

Что она покажет:

| Строка в выводе | Что значит |
|---|---|
| `встройка: …` | нашлась встройка Alloha — ссылка правильная |
| `озвучек: 8` и список | открытый API ответил, озвучки есть |
| `Плеер не отдал страницу` | Alloha закрыла плеер: обычно регион либо другой адрес |
| `hlsSource: N озвучек — ПОЛУЧЕНО` | **готово**, поток получен, адреса в файле |
| `пусто. Тело ответа …` | плеер открылся, но адреса не отдал — пришлите отчёт |

В конце печатается путь к отчёту: `alloha_check\<дата>_summary.txt`.

## Что прислать мне

Один файл — этот `summary.txt`. Если в выводе было `ПОЛУЧЕНО`, то ещё и
`<дата>_hlsSource.json`.

## Если хочется без приложения

Есть и отдельный пробник, он делает то же самое, но не требует, чтобы
проект был установлен:

```
python tools\alloha\probe_bnsi.py "ССЫЛКА_НА_СТРАНИЦУ"
```

⚠️ Прошлый раз я дал именно его с `python3` — отсюда и ошибка. Ещё одна
причина запускать `-m tvhost2.alloha_check`: пробник не видит настроек
приложения, а команда — видит.

## Чего точно делать не надо

- Ставить Python из Microsoft Store «чтобы появился python3» — не нужно,
  у вас нормальный Python 3.12.8.
- Создавать ярлык `python3.exe` — тоже не нужно.
- Менять PATH — не нужно.

## Одно замечание по моей же команде

Я проверил диагностику на живом сайте и нашёл слабое место: на странице
бывает **две** встройки Alloha — одна с `kp=`, другая с `token=`. Сейчас
берётся первая с `kp=`, а открытый API требует `token=`, поэтому список
озвучек может оказаться пустым там, где он есть. В выводе это видно по
строке `токен сайта: …`. Если она пустая — напишите, поправлю выбор встройки
первым делом.
