# Alloha: что запустить и почему прошлая команда не сработала

## Почему `python3` не нашёлся

Python у вас **есть** — `python --version` показывает `Python 3.12.8`.
Не сработало вот что: в Windows команда установщика называется `python`,
а `python3` — это ярлык-заглушка из Microsoft Store. Она есть всегда, но
настоящий Python по ней не запускается, и выходит сообщение
«Python was not found; run without arguments to install from the Microsoft
Store». Настоящий Python при этом жив — просто зовут его иначе.

Правило простое: **в Windows — `python` (без цифры 3), в Linux — `python3`.**
Это моя ошибка в инструкции, я писал под Linux.

## Что запустить (два шага)

Ошибка `ModuleNotFoundError: No module named 'tvhost2'` — это уже не про
Python, а про то, что пакет лежит в подпапке `src\` и в системный Python не
установлен. Поэтому `python -m tvhost2.alloha_check` его не видит. Ставить
пакет не надо: в проекте и так есть окружение `.venv`, которое `start.bat`
создал при первом запуске.

### Шаг 1 — обновиться

В папке проекта:

```
git pull
```

Должна появиться строка **`93f8578 fix(alloha): check_alloha.bat`** или новее
(`git log --oneline -1`).

### Шаг 2 — двойной щелчок по `check_alloha.bat`

Он появился в папке проекта после `git pull`. Щёлкните дважды — спросит
ссылку, вставьте её и нажмите Enter.

Либо сразу с ссылкой, из консоли:

```
check_alloha.bat "https://zlord.org/25672-xorosaia-doc.html"
```

Почему именно он: батник берёт `.venv\Scripts\python.exe` и ставит
`PYTHONPATH=src` — ровно так, как это делает `start.bat`. Ничего
устанавливать и настраивать не нужно, окно приложения закрывать не надо
(команда только читает).

### Что покажет

| Строка в выводе | Что значит |
|---|---|
| `встройка: …` | нашлась встройка Alloha — ссылка правильная |
| `озвучек: 8` и список | открытый API ответил, озвучки есть |
| `Плеер не отдал страницу` | Alloha закрыла плеер: снаружи России это норма, у вас — быть не должно |
| `hlsSource: N озвучек — ПОЛУЧЕНО` | **готово**, поток получен |
| `пусто. Тело ответа …` | плеер открылся, но адреса не отдал — пришлите отчёт |

В конце печатается путь к отчёту: `alloha_check\<дата>_summary.txt`.

### Что прислать мне

Один файл — этот `summary.txt`. Если было `ПОЛУЧЕНО` — ещё `<дата>_hlsSource.json`.

## Чего точно делать не надо

- Ставить Python из Microsoft Store «чтобы появился python3» — не нужно,
  у вас нормальный Python 3.12.8.
- Создавать ярлык `python3.exe` — тоже не нужно.
- Менять PATH — не нужно.
