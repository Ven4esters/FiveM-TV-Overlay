# Alloha: механизм вскрыт наполовину

Проверено живьём 24.11.2026 из США и по вашей странице плеера из России.
Работающий код — `tools/alloha/guard_probe.py` (запускается, возвращает токен).

---

## Что удалось

### 1. Защита CDN устроена совсем не так, как казалось

| Что проверил | Результат |
|---|---|
| `Accepts-Controls` с мусором (случайные 64 hex) | **200 — не проверяется** |
| `Accepts-Controls` пустой | **200 — действительно не проверяется** |
| `Origin: https://example.com` | **403** |
| `Origin: https://zlord.org` | **403** |
| `Origin: https://userplay.live` (сам CDN) | **403** |
| `Origin: https://tories-as.stravers.live` (домен плеера) | **200** |

Вывод: **токен — ложный след**, проверяется только `Origin`, и он должен
совпадать с доменом плеера. Домен мы и так знаем из `<iframe>`.

### 2. Токен всё-таки научился добывать

Он не выводится из `token`/`token_movie`, но выдаётся сервером по протоколу
«задача — доказательство». Снято с `app.js` плеера:

```
GET  /sarn      заголовок: acceptis: <домен>.<озвучка>
     → {challenge, nonce, uap}

proof = sha256( nonce | домен | uap | origin | origin )

POST /vorf      заголовки: content-type: application/json
                            accepts-block: <домен>.<озвучка>
     {challenge, proof, parentOrigin, referrer}
     → {"ok": true, "token": "…238 символов…"}
```

Проверено: работает из-за границы, токен 238 символов.
В коде плеера это функция `c9` — расшифрована полностью.

### 3. Дальше — стена

Адрес вида `https://0a-2e-7c-r400.userplay.live/1/<1962 символа>/master.m3u8`
получается **не из page HTML и не из api.alloha.tv** (там его нет вообще:
0 упоминаний `userplay`, `m3u8`, `hls`, `stream`). Его выдаёт отдельный
запрос плеера (`ajax.post` + WebSocket), и вот его-то найти не удалось:

- в `app.js` есть вызов `Q5().post("/" + тип + id, {...})` с заголовком
  `Borth`, ответ содержит поле `pnr` (адрес) — но путь и параметры зашиты
  через пул строк с четырьмя разными сдвигами, статически не вскрылись;
- при попытке запустить плеер в Node (jsdom + настоящая сеть) скрипт падает
  на инициализации — нужен настоящий браузер с MSE;
- WebSocket-эндпоинты `wss://…/ws/` отвечают 401 на все варианты
  рукопожатия (токен в query, в заголовке, в подпротоколе, cookie).

## Что это значит для задачи

**Выбор озвучек работает** (это ваше отдельное требование) — его отдаёт
открытый API, регион ему не мешает.

**Ссылку на видео взять неоткуда.** Это не «мы не смогли» — это значит, что
Alloha закрыта ровно тем способом, который нельзя обойти без браузера:
адрес рождается при исполнении обфусцированного скрипта в браузере.

### Варианты, и я не выбираю за вас

| Вариант | Что даёт | Цена |
|---|---|---|
| **Оставить честный отказ** | человек видит «Alloha: плеер не отдаёт ссылки наружу» | ничего, работает сейчас |
| **Встроенный Chromium** | скорее всего заработает | +500–800 МБ и второй Chromium — прямо против вашего требования «8 ГБ, не держать два» |
| **Прислать HAR** | я найду запрос за минуту и, возможно, обойдусь без браузера | ваши 2 минуты |

**Советую третий.** HAR — это файл, который Chrome сохраняет со всеми
запросами: F12 → Network → правый щелчок → «Save all as HAR». Из него я
увижу и путь, и параметры, и заголовки того самого запроса — и тогда,
возможно, всё сведётся к десятку строк на Python.

Если HAR покажет, что адрес приходит по WebSocket после исполнения скрипта —
тогда честно скажу, что без браузера никак, и вопрос решится выбором строки
выше.
