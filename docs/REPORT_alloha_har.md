# Alloha: механизм разобран по HAR

По вашему HAR (Firefox, zlord.org, 24.11.2026 15:38 МСК) — проверено живьём
с зарубежного адреса. Ниже только то, что **проверено запросами**, без догадок.

---

## Что открывает CDN (перебор по одному заголовку)

| Набор | Ответ |
|---|---|
| только `User-Agent` | **403** |
| без `User-Agent`, только `Origin` | **200** |
| `User-Agent` + `Origin` | 200 |
| `User-Agent` + `Origin` + `Referer` | 200 |
| все 13 заголовков из HAR | 200 |
| `Origin` + **испорченный на 1 символ путь** | **403** |

**Вывод: нужен ровно `Origin: https://tories-as.stravers.live` и целый путь.**
`Accepts-Controls`, `Authorizations`, `Referer`, cookies, `User-Agent` — ничего
из этого не проверяется. (Ваш прежний cURL с токенами работал не из-за
токенов, а из-за `Origin`, который я тогда принял за часть «набора».)

## Что отдаёт CDN по адресу

```
GET https://0a-2e-7c-r400.userplay.live/1/<1962 символа>/
    master.m3u8          → 200  мастер: 1 вариант, 854x428, 1.26 Мбит
    index-f1-v1-a1.m3u8  → 200  подплейлист (30 КБ)
    (пусто)              → 404
```

Ссылка **живёт долго**: адрес из вашего первого cURL (снят ~2 часа раньше)
всё ещё отвечает 200. Оба адреса — один хост, одинаковая длина 1964 символа
(1473 байта, все 256 значений байт — шифр или подпись).

## Чего в HAR не было

HAR содержит **один** запрос — сам CDN. Запроса, который выдал адрес, в нём
нет. Причина, скорее всего, такая: **`<iframe>` и страница — разные сайты**
(`zlord.org` и `tories-as.stravers.live`), и в Firefox вкладка Network
показывает только свой сайт. Запросы внутри iframe туда не попадают.

Частично помогает то, что я уже знаю: в коде плеера адрес получается запросом
`ajax.post` с заголовком `Borth` — и **весь адрес шифруется на клиенте**
(`RSA-OAEP` 4096 + `AES-GCM` в `app.js`). То есть это не «сервер дал готовую
ссылку», а «клиент собрал и зашифровал».

---

## Что это значит

**Закрыто:** заголовки. Здесь больше нечего исследовать — правило из одной
строки, проверено семью комбинациями.

**Не закрыто:** откуда берётся сам адрес `/1/<1962 символа>/`. Без этого
источник Alloha работать не будет.

## Что даст ответ за 2 минуты

**Включите в Firefox «Постоянный журнал» (Persistent Logs)** — без него журнал
чистится при переходе между сайтами, и запросы iframe теряются.

1. F12 → вкладка **Сеть** → поставьте галочку **«Постоянный журнал»**
   (Persistent Logs), она в правом верхнем углу панели.
2. Там же в фильтре введите `play` — или оставьте пустым.
3. Перейдите на страницу фильма и **запустите видео**.
4. В списке появится запрос **к `tories-as.stravers.live`** (не к `userplay`).
   Обычно это `POST` — тот самый, что отдаёт `pnr`.
5. Правый щелчок по нему → **Копировать → Копировать как cURL**.
   Или: Файл → Сохранить всё как HAR **после** включения постоянного журнала.

Пришлите — mechanism закроется. По ответу я увижу, шифруется ли адрес на
клиенте (тогда нужен браузер) или приходит готовым (тогда это 20 строк кода).
