# Как обновиться до последней версии

Коротко: `git pull` в папке проекта и **перезапустить приложение**.

Почему перезапуск обязателен: прокси живёт в том же процессе, что и окно.
Пока окно открыто, выполняется старый код — даже если файлы на диске уже
новые. Python читает модуль один раз при запуске.

---

## Шаг за шагом

### 1. Закрыть приложение

Совсем: окно исчезло и в трее ничего не осталось. Если не уверены —
откройте диспетчер задач и проверьте, что нет `python.exe` с `tvhost2`.

### 2. Обновиться

В папке проекта (там, где лежит `pyproject.toml`):

```bash
git pull
```

### 3. Проверить, что обновилось именно то

```bash
git log --oneline -1
```

Должна быть строка **`refactor: Alloha удалена из проекта`** или новее.
Если видите что-то более старое — `git pull` не сработал
(бывает, если в папке есть свои правки: `git stash`, потом `git pull`).

### 4. Запустить заново

```bash
python -m tvhost2.ui --serve
```

## Если `git pull` не работает

Три частые причины:

**«Your local changes would be overwritten»**
В папке есть ваши правки. Если они не нужны:
```bash
git stash
git pull
```

**«Not a git repository»**
Папка скачана архивом, а не клонирована. Скачайте заново:
```bash
git clone https://github.com/Ven4esters/FiveM-TV-Overlay
```

**«Permission denied» / просит пароль**
Проект публичный, пароль не нужен. Проверьте адрес:
```bash
git remote -v
```
Должно быть `https://github.com/Ven4esters/FiveM-TV-Overlay`.
