### 🟡 2. Alloha на yummyani — сделать по-настоящему

Сейчас на old.yummyani.me работает только Kodik. При этом у «Агента
времени» 38 записей через Alloha, и они мимо нас.

**Что мешает:** в ссылке yummyani нет id Кинопоиска (`kp`), а есть только
`token_movie`. Открытый API Alloha ищет по `kp` или по названию.

**Что нужно:** сопоставить тайтл yummyani с id Кинопоиска. Это делается
запросом по названию (`api.alloha.tv/?token=…&name=…`) — я проверил, такой
запрос работает и отдаёт нужный тайтл. Работы примерно на 2–3 часа плюс
проверка на десятке тайтлов, чтобы не перепутать одноимённые.

**Польза:** +38 озвучек на «Агенте времени» и Alloha-записи на всех
остальных тайтлах yummyani.

### 🟢 4. Обёртка над Alloha для «горячего» переключения

Сейчас переключение озвучки = повторный разбор (заново страница, API,
плеер). На Alloha это 4–5 секунд. Можно кэшировать `fileList` на сессию и
переключать за доли секунды — так уже сделано для Kodik.

**Работы:** 1–2 часа. **Польза:** скорость, а не новые сайты.
