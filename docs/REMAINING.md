### ✅ 2. CVH на yummyanime и на всех сайтах с этим плеером

**Сделано 24.11.2026.** Оказалось, что это один и тот же плеер, а не два
похожих: различий между anidub.org и yummyanime ровно два числа —
`aggr` (`cvh` / `mali`) и `pub` (`19` / `745`). Разбор вынесен в общий
`cvh.py`; сайт приносит только свои числа и название.

Что выяснено из бандла `iframeCVH` (в HTML плеера нет, его собирал JS):

| Что | Значение |
|---|---|
| `data-aggregator` | `mali` |
| `data-publisher-id` | `745` |
| `data-title-id` | `anime_id` из адреса обёртки (61967), **не** `page_id` каталога (21747) |
| `priority-voice` | `dubbing_code` из адреса |
| `episode` | номер серии из адреса |

Итог: озвучки обоих плееров в одном списке (у «Чёрного клевера» 14 Kodik
+ 8 CVH = 22), CVH отдаёт до 1080p прямым mp4, серии переключаются общим
механизмом. Новый сайт с этим плеером подключается одной функцией
`cvh.build_stream`.
