# ADR-0002: HTTP-сервер слушает только доверенную сеть

**Дата:** 2026-11-23
**Статус:** принято

## Контекст

Линтер (bandit) предупреждает: `urllib.request.urlopen(url)` с адресом,
пришедшим из запроса, — это потенциальный SSRF. Кроме того, сервер
слушает `0.0.0.0`, то есть доступен из локальной сети.

Сервер отдаёт видео на телевизор в игре — он обязан быть доступен
по локальному IP. Слушать только `127.0.0.1` нельзя: телевизор
не сможет подключиться.

## Решение

Принять ограничение осознанно, зафиксировать и смягчить:

1. **SSRF принимается как свойство продукта**: задача прокси — ходить
   по ссылкам, которые ввёл пользователь. Это не «уязвимость», а функция.
   Правило `S310` отключено в `pyproject.toml` с этой ссылкой.
2. **Слушаем `0.0.0.0`** — иначе телевизор не подключится. Правило `S104`
   отключено там же.
3. **Смягчение**: на границе валидируется схема (`http`/`https`),
   а `file://` и `ftp://` отклоняются. Подписанные параметры вырезаются
   из логов (`SECRET_QUERY_KEYS`).
4. **Предупреждение пользователю** в README: прокси не имеет
   аутентификации и не должен быть доступен из интернета.

## Последствия

- Порт 9000 нельзя пробрасывать наружу — это записано в README;
- при добавлении аутентификации решение пересматривается (ADR-0005, план).

## Что НЕ делаем

- Не вводим токен доступа: телевизор в GTA не умеет передавать заголовки
  в браузерном URL, это сломает основной сценарий.
