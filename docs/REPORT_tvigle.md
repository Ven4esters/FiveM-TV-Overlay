# tvigle.ru: разбор и почему отсюда не играет

Единственный сайт из той пятёрки, что остался в проекте после отказа от
плеера Alloha (26.11.2026). Проверено живьём 24.11.2026.

> **Сервер, с которого шли проверки, стоит в США.**
> Приложение запускается на вашем компьютере в России.

tvigle закрывает видео **по стране**: из США API отвечает
`isGeoBlocked: true`, с российского адреса отдаёт `videos` с m3u8. Это не
поломка разбора — сайт сам так говорит.

---

## tvigle.ru — лицензия на РФ

`https://www.tvigle.ru/video/kruche-nekuda/`

Сайт устроен просто и честно — открытый API без ключей и cookies:

```
GET страница → <meta property="og:video" content="…/video/5838418/?…">
GET cloud.tvigle.ru/api/play/video/5838418/?partner_id=24
    → {"playlist":{"items":[{"title":"Круче некуда",
                             "videos":{"hls":"…m3u8"},
                             "isGeoBlocked":false}]}}
```

Отсюда наш ответ:

```
isGeoBlocked: true
errorMessage: «Ограничение по территории. Нам очень жаль, но сейчас это
               видео недоступно для просмотра в вашей стране.»
```

**Это лицензия, а не защита.** Из России API отдаёт `videos` с m3u8, и мы
его разбираем. Обходить региональные ограничения мы не будем и не советуем.

**Про выбор озвучки честно: у tvigle его нет.** Это лицензионный показ
одного перевода, а не сборник дубляжей. Требование «есть выбор озвучки»
здесь выполнить нечем — поэтому в интерфейсе источник помечен так, чтобы
не обещать лишнего.
