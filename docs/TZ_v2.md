## 3. Архитектура v2

### 3.1 Слои (направление зависимостей — только вниз)

```
┌─────────────────────────────────────────────┐
│  ui/        окно, пульт, сообщения          │  PySide6
├─────────────────────────────────────────────┤
│  app/       сценарии: «открыть ссылку»,     │  без Qt, без сокетов
│             «переключить качество»          │
├─────────────────────────────────────────────┤
│  sources/   по одному файлу на источник     │  чистые функции
│             rutube.py vk.py youtube.py …    │
├─────────────────────────────────────────────┤
│  stream/    HLS-мост, сегменты, Range       │  HTTP
├─────────────────────────────────────────────┤
│  core/      модель данных, ошибки, события  │  вообще без зависимостей
└─────────────────────────────────────────────┘
```

**Почему так:** новый источник = новый файл в `sources/`. Не трогаем
ни прокси, ни интерфейс. Это главное требование к переписыванию.

### 3.2 Единый контракт источника

Каждый источник — класс с одинаковым набором методов. Никаких `if is_vk`
по всему коду.

```python
class Source(Protocol):
    name: str                    # "Rutube"
    def matches(self, url) -> bool:
        """Этот источник умеет такую ссылку?"""

    def resolve(self, url) -> Stream:
        """Ссылка → поток: адреса качеств, битрейты, заголовки."""

    def explain_error(self, exc) -> str:
        """Понятное человеку объяснение: что случилось и что делать."""
```

Добавить источник = написать один класс + один тест. Всё.

### 3.3 Модель данных (одна на весь проект)

```python
@dataclass(frozen=True)
class Quality:
    height: int          # 1080
    width: int           # 1920  ← отдельно, для вертикальных видео (ERR-062)
    bitrate_kbps: int    # 5884  ← реальный, для BANDWIDTH (ERR-067)
    url: str

@dataclass(frozen=True)
class Stream:
    source: str                  # "Rutube"
    title: str
    qualities: list[Quality]     # от лучшего к худшему
    kind: StreamKind             # HLS | MP4 | HLS_MUX
    headers: dict[str, str]      # Referer, Cookie — если нужны
```

Одна структура — и прокси, и плеер, и интерфейс говорят на одном языке.

## 5. Проверка работоспособности: как это будет

### 5.1 Три уровня проверки

| Уровень | Что проверяет | Когда |
|---|---|---|
| **Юнит** | логика без сети: разбор ссылок, Range, битрейты | каждый коммит, 3 сек |
| **Интеграция** | прокси отдаёт плейлист и сегмент | каждый коммит, 40 сек |
| **Живьём** | настоящий Chromium играет видео | перед каждым релизом, 3 мин |

Третий уровень — то, что вы видели: `readyState=4`, время идёт, ошибок 0.

### 5.2 Что мне нужно от вас для проверки

Вы написали «пришлю свои ссылки». Для каждого источника нужно **по одной**:

- открывается в браузере **без входа в аккаунт**;
- видео, не стрим (стрим проверить сложнее — он может кончиться).

🔴 **Формат, который мне удобен** (скопируйте и заполните):

```
Rutube:    https://rutube.ru/video/e1c3757f9a3db09a224ac95c836cecbf/   ← уже есть, спасибо
VK:        https://vkvideo.ru/video-220020068_456260705              ← уже есть, спасибо
YouTube:   (любое публичное видео)
Twitch:    (запись или клип, не живой стрим)
Vimeo:     ?
Dailymotion: ?
Rumble:    ?
PeerTube:  ?
Archive:   ?
OK.ru:     ?
Kodik:     ?   ← особенно нужен: свой разбор, без вашей ссылки не проверить
```

Те, что с «?», я могу найти сам в открытом доступе — но если пришлёте свои,
проверю именно то, что нужно вам.

### 5.3 Если тест не проходит — что я пришлю вам

Не «не работает, разбирайтесь». А:

1. **Что именно** я нажал (ссылка, кнопка, время);
2. **Что ожидал** увидеть;
3. **Что произошло** — скриншот + последние 20 строк журнала;
4. **Что проверить вам** — по шагам, простыми словами;
5. **Что я подозреваю** и что сделаю дальше.

Пример:

> **Тест Vimeo не прошёл.** Ссылка `vimeo.com/123456`.
> Ожидал: плеер с видео. Произошло: `manifestLoadError` через 8 секунд.
> В журнале: `CDN не отдал плейлист, code=403`.
> **Проверьте у себя:** откройте эту ссылку в обычном браузере — играет?
> Если да — у Vimeo защита по IP, и с вашего домашнего адреса сработает.
> Если нет — видео приватное, нужна другая ссылка.

## 8. Технические решения (обоснованные)

| Решение | Почему так, а не иначе |
|---|---|
| **yt-dlp как движок** | 1755 экстракторов, обновляется каждую неделю командой. Свой парсер каждого сайта — это 1755 файлов поддержки |
| **Свой разбор только для Kodik/AnimeGo** | Их нет в yt-dlp, но они нужны вам для озвучек |
| **HTTP-сервер стандартный** | Уже проверен: 128 соединений, Range, CORS. Переписывать незачем |
| **hls.js в браузере игры** | Единственный способ играть HLS в старом браузере CEF. Нативный HLS в игре не работает |
| **Прокси локальный, 127.0.0.1** | Обход CORS + ссылки не протухают. Наружу ничего не торчит |
| **Реальный BANDWIDTH** | ERR-067: завышение на 47% → вечное 144p |
| **BOM в .bat** | ERR-064: без него cmd ломает кириллицу |

## 9. Что может пойти не так (честно)

| Риск | Вероятность | Что тогда |
|---|---|---|
| Сайт поменяет защиту | **высокая**, это норма | Источник помечается 🔴, вы присылаете ссылку, чиню |
| DRM-сайт (Netflix, Kinopoisk) | 100% | Не будет никогда. Объясняю в интерфейсе, почему |
| Ссылка привязана к сессии браузера | средняя | Есть «Закрепить»: прокси скачает файл к вам |
| Стрим Twitch кончился | всегда | Для стримов — отдельное поведение, предупреждение |
| Ваш интернет медленный | зависит | ABR сам снизит качество. 1080p требует ~7 Мбит/с |
| Сайт блокирует российские IP | средняя | Обхожу заголовками; если нет — честно говорю |

**Я не обещаю «работает всё всегда».** Обещаю: когда ломается, вы видите
**почему** — в интерфейсе и в журнале, а не «ошибка».

| **HLS** | Способ отдавать видео «кусочками». Так работают Rutube, VK, Twitch |
| **m3u8 (плейлист)** | Список этих кусочков: какие есть, в каком порядке |
| **Сегмент** | Один кусочек видео, обычно 2–6 секунд |
| **master-плейлист** | Список качеств: «1080p — вот ссылка, 720p — вот» |
| **BANDWIDTH** | Сколько мегабит в секунду нужно для качества. Если врёт — плеер не поднимет качество |
| **ABR** | Автоподбор качества по скорости интернета |
| **YouTube-DL** | Готовая библиотека, которая умеет разбирать 1755 сайтов. Мы её используем, а не пишем 1755 парсеров |
| **DRM** | Замок на видео: чтобы смотреть, нужен ключ от сайта. Netflix так защищён |
| **Прокси** | Посредник на вашем компьютере: игра просит видео у него, он — у сайта |
| **Range** | «Дай мне с 500-го по 1000-й байт» — так работает перемотка |
