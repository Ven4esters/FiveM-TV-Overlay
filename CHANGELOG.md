# Что вошло в v2

Версия **2.0.0** — переписывание по модулям от ядра к интерфейсу. v1 оставлен
в репозитории и в теге `v1.0-working`: если v2 где-то подведёт, есть куда
вернуться.

Сборка: `python -m build` → `tvhost-2.1.0.tar.gz` и `.whl`.

# 2.1.0 — 24.11.2026

Тег `v2.1`. Что вошло с 2.0.0, по порядку.

## Серии и озвучки — общий механизм, а не kodik-овский

Заказчик: «все изменения должны работать на всех наших источниках, а не
только в kodik; при этом не везде есть озвучки и серии».

- `Stream` получил `episode_season`, `can_switch_episode` и свойство
  `has_episodes`. Пустой список серий и «источник не умеет» — разные вещи:
  раньше по ним обоим рисовался переключатель.
- `resolver.resolve(url, translation_index=None, episode=None)` ходит в
  источник через `_ask`: перебирает наборы параметров (оба → перевод →
  серия → ничего) и по `TypeError` понимает, что источник этот довод не
  принимает. Rutube, YouTube, VK, Twitch, OK.ru, Tvigle просто не получают
  `episode` — падать им не за что.
- `session.episode_url` больше не знает имён сайтов наизусть: спрашивает у
  источника метод `url_with_episode`. Новый сериальный сайт заработает сам.
- Серия проверяется по **выбранной** озвучке: у Amazing Dubbing и Solomon
  по 8 серий, у Домика Сумасшедших Дабберов — 4. Просьба про 5-ю серию там,
  где их четыре, — честный отказ, а не тихая подмена.
- Пульт показывает выбор серии по `canSwitchEpisode` из `/state`.

## CVH на всех сайтах этого плеера

cdnvideohub на anidub.org и yummyanime — один плеер, а не два похожих:
различий ровно два числа, `aggr` (`cvh` / `mali`) и `pub` (`19` / `745`).
Разбор вынесен в общий `cvh.py`. Подробности — ниже, в разделе «Что нового
после 2.0.0».

## Упаковка

- Команда `tvhost` теперь запускает v2 (было — v1).
- `hls.min.js` едет в колесе (раньше установленный сервер отдавал страницу
  без плеера).
- Код v1 исключён из сборки; lint-исключения под него убраны, v1 выведен
  из проверки целиком.

## Пять жалоб заказчика

Тумблеры «Звук»/«Развернуть», подсказка субтитров (у Kodik «субтитры» —
это озвучка `translation_type=subtitles`), замер нормализации при открытии
с причиной из `note`, непрыгающий размер окна, серия из `serial-series-box`
вместо `vInfo` (там лежала 8-я серия — отсюда «играет не то»).

## Что нового после 2.0.0

- **CVH на всех сайтах этого плеера (24.11.2026).** Оказалось, что
  cdnvideohub на anidub.org и на yummyanime — один и тот же плеер, а не
  два похожих: различий ровно два числа, `aggr` (`cvh` / `mali`) и `pub`
  (`19` / `745`). Разбор вынесен в общий `cvh.py`, `anidub_org.py` стал
  тонким. На yummyanime плеер вообще не виден в HTML — его собирал
  бандл `iframeCVH`; параметры прочитаны из бандла (`data-aggregator=mali`,
  `data-publisher-id=745`, `data-title-id=<anime_id из адреса>`). Теперь
  озвучки обоих плееров лежат в одном списке: у «Чёрного клевера 2»
  14 Kodik + 8 CVH = 22, до 1080p прямым mp4. Попутно исправлен разбор
  mp4: контейнер `moov` у okcdn весит 1,1 МБ, а читаем мы 256 КБ, и
  прежний обход терял все качества молча.

- **Упаковка: команда `tvhost` теперь запускает v2 (24.11.2026).**
  Раньше точка входа вела в `tvhost.__main__` — то есть `pip install`
  ставил команду от старой версии, хотя пакет назывался 2.0.0. Заодно
  `hls.min.js` не попадал в колесо: установленный сервер отдавал страницу
  без плеера. Теперь `package-data` прописан для `tvhost2`, v1 исключён из
  сборки (`exclude`), а 9 блоков lint-исключений под `src/tvhost/**`
  убраны: v1 выведен из проверки целиком (`extend-exclude`), потому что
  гасить 310 замечаний архива списком исключений — не то же самое, что
  содержать код в порядке. Проверено установкой в чистое окружение: страница 200,
  `hls.min.js` 200 (413 КБ).

- **Alloha удалена (26.11.2026).** Плеер разобран до конца — вплоть до
  подписанного пропуска в `Borth` из меты страницы, — но сервер не отдал
  адреса ни на одной из десяти проверок, в том числе с точным повтором
  запроса браузера, настоящим отпечатком и свежим пропуском. Заказчик
  отказался от плеера. Удалены: источник, диагностика (`alloha_check`,
  `replay_alloha`), тесты и разборы в `docs/`. Сайты zlord.org,
  lordserialc.run и mltclb2.icu больше не поддерживаются.

- **История просмотров** — недавние в пульте, до пяти, в памяти на одну
  сессию. Клик по записи открывает видео заново. Дедупликация по
  «ссылка + озвучка»: дубляж и субтитры считаются разными просмотрами.
- **Сайты с плеером Kodik** поддерживаются автоматически — отдельный
  список доменов не нужен: плеер узнаётся в разметке страницы.
- **YummyAnime** — через открытый `/api/anime/<id>/videos`.
- **Подсказка об отказе не исчезает.** Раньше опрос пульта каждые 800 мс
  перезаписывал её словами «играет 0:00 / 0:00», и человек не успевал
  прочитать. Теперь отказ держится, пока не откроют другое видео или не
  закроют его крестиком, и сопровождается отдельной строкой «что делать».

## Источники

| Источник | Что умеет |
|---|---|
| **Rutube** | обычные и «живые» ссылки, выбор качества |
| **VK Видео** | мультиплекс, звук, вертикальные ролики |
| **YouTube** | H.264 без VP9, склейка дорожек через ffmpeg, прямой эфир |
| **Kodik** | вскрыт полностью: шифр, API, все озвучки |
| **Twitch** | живые каналы, записи, клипы |
| **OK.ru** | через обходной путь yt-dlp |
| **anidub.com** | серии, списки онгоингов, плейлист (старый плеер) |
| **anidub.org** | новый плеер: до 1080p, 9 озвучек на выбор |
| **Kodik (встройка)** | любой сайт, где видео встроено плеером Kodik: ani-media.online и подобные |
| **YummyAnime** | old.yummyani.me через открытый API; только то, что отдано через Kodik |
| **Tvigle** | tvigle.ru: открытый API плеера, лицензия на РФ, одна дорожка |

YouTube отдаёт «подтвердите, что вы не робот» — это его защита, и обходить её
сознательно не стали. При таком ответе плеер честно говорит, что ссылка
не годится, вместо того чтобы показывать чёрный экран.

hdrezka из объёма исключена по решению заказчика: Anubis и гео-блок
с зарубежного адреса.

## Плеер в игре

Переписан на v2. Кнопки на странице плеера, потому что в CEF внутри GTA 5
нет ни клавиатуры, ни браузерных средств:

- пауза/продолжить, «−10 с», «+10 с», звук, полный экран;
- полоса перемотки с буфером: тянется мышью, превью времени, буфер виден;
- ползунок громкости, иконка меняется при выключении звука;
- панель прячется сама через 2,5 с, но не уходит на паузе, под курсором
  и во время перетаскивания;
- клик по картинке — пауза;
- прямой эфир: полоса превращается в метку «ПРЯМОЙ ЭФИР», перемотка
  недоступна и говорит об этом;
- полный экран с запасным вариантом для CEF, где Fullscreen API нет.

## Звук

Нормализация громкости EBU R128. Раньше разброс между роликами достигал
19 дБ и приходилось крутить громкость на каждый; теперь 11 дБ.

## Пульт

- одна команда запуска: `python -m tvhost2.ui`;
- вкладки «Пульт», «Источники», «Журнал»;
- версия видна в заголовке окна — при разборе проблемы сразу понятно,
  какая сборка у человека.

## Проверки

- 702 теста собрано (в CI 672 проходят, 15 живых отсеяны), покрытие 68 %
  (порог в CI);
- ruff и mypy без замечаний, 60 модулей v2;
- в CI три задания: безопасность, линтер/типы/тесты, регресс на живых

## Что осталось честно сказать

- **Серии у CVH выбираются «ближайшей меньшей».** Если просить 5-ю у
  тайтла из трёх, откроется 3-я, а не отказ: плеер не сообщает, сколько
  серий у каждой озвучки. У Kodik в такой ситуации честный отказ.
- **v1 в репозитории, но не в сборке.** Он остаётся для отката, тесты v1
  работают из исходников.

- **YouTube bot-check не обходим.** Часть ссылок не заиграет, плеер скажет
  об этом прямо.
- **hdrezka не поддерживается** — по решению заказчика.
- Память под нагрузкой замерена не была: цифры не выдумываю.
